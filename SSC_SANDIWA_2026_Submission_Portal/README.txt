SSC SANDIWA 2026 Submission Portal (Frontend Prototype)

HOW TO PREVIEW
1. Extract this ZIP.
2. Open index.html in a modern browser.
3. No server or database is needed for this frontend-only prototype.

DEPLOY TO VERCEL
1. Upload the project folder to GitHub.
2. Import that repository in Vercel.
3. Set Root Directory to the folder that directly contains index.html.
4. Use Framework Preset "Other"; leave Build Command and Install Command blank.
5. Set Output Directory to "." and deploy.

NOTES
- This is a static frontend prototype, not a deployed website.
- Google Forms and Google Drive handle file upload/storage after their links are connected.
- The six submission buttons are connected to their configured Google Forms.
- Google Forms file-upload settings and account restrictions are controlled in Google Forms; respondents may need to sign in.
- The page does not currently verify uploads, record submissions, or enforce deadlines itself.
- Confirm the exact scope of the two-point deduction rule with the official competition mechanics before publishing.
- The SSC seal is embedded in index.html, so it does not depend on a separate image file being included in the deployment.
